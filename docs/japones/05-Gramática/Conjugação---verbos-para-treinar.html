Resumo das regras do Grupo 1 (godan)

Finalますて / たないImperativoExemplo
ういって / ったわえ買う → 買って
つちって / ったたて待つ → 待って
るりって / ったられ帰る → 帰って
むみんで / んだまめ飲む → 飲んで
ぶびんで / んだばべ遊ぶ → 遊んで
ぬにんで / んだなね(só 死ぬ)
くきいて / いたかけ書く → 書いて
ぐぎいで / いだがげ泳ぐ → 泳いで
すしして / したさせ話す → 話して

Exceções que enganam

  • 行く não faz 行いて: faz 行って / 行った.
  • 帰る, 入る parecem Grupo 2 mas são Grupo 1 (帰って, 入って).
  • 来る muda a leitura: き (ます, て, た), こ (ない), こい (imperativo).
  • Substantivo + する (勉強する, 散歩する) conjuga como する.

Verbos com します

勉強します (estudo), 勉強して (estude e…), 勉強しない (não estudo), 勉強した (estudei).

Forma て de 飲む?

Resposta

飲んで

Forma ない de 買う?

Resposta

買わない (う → わ).

Forma た de 行く?

Resposta

行った (exceção: não é 行いた).

Imperativo de 食べる?

Resposta

食べろ

Forma ない de 来る?

Resposta

来ない (こない).
